# SkillBridge KZ — Landing Page

The public website of **SkillBridge KZ**, a platform that helps college students in Kazakhstan
find safe internships and first jobs with verified employers.

- **Live site:** https://skillbridge-kz-demo.vercel.app
- **The SkillBridge platform:** https://skillbridge-black-delta.vercel.app
  ([source code](https://github.com/MoldashDariya/skillbridge))

The site is available in Kazakh, Russian and English. It includes video testimonials from pilot
students with subtitles in all three languages, and three short interactive games about job safety
and hiring. The students' videos are published with their consent (and their parents' consent for
minors).

Built with Next.js 14, TypeScript and Tailwind CSS. All site text lives in `src/lib/content.ts`.

## Running locally

```bash
npm install
npm run dev
```
